**Pergunta:** Como funciona o processo de encaminhamento de leads gerados pelo time de SDR da Wake para as agências parceiras?

**Resposta:** O time de SDR da Wake prospecta ativamente leads qualificados e os encaminha diretamente ao grupo de parceria via WhatsApp. Cada lead inclui:

- Plataforma atual
- ERP em uso

- Comentários sobre necessidade e urgência

### TRB-003 — Integração técnica Wake API Pública vs. Data Wake para a Biso

| Campo | Valor |
|---|---|
| **Grupo/Chat** | Wake & Biso |
| **Data** | 2025-12-22 |
| **Categoria** | `troubleshooting` |
| **Tags** | `integração`, `audience-solutions` |

**Sintomas:** Durante a integração técnica Biso + Wake, havia dúvida sobre qual API usar para exportação e cruzamento de dados de produtos e vendas.

**Causa raiz:** O Data Wake é projetado apenas para consultas em tempo real e não atende ao caso de uso da Biso (salvar dados em seus servidores para cruzar com mídia, marketplaces e logística).

**Resolução:** Decisão técnica documentada —
- **Data Wake foi descartado** para este uso. Ele deve ser utilizado apenas para consultas em tempo real
- **Motivo:** A Biso precisa salvar dados em seus servidores para cruzar com outras fontes (mídia, marketplaces, logística) — isso não é compatível com o modelo do Data Wake
- **Solução definida:** Usar **API Pública + API Storefront**

**Query de referência (GraphQL — API Storefront) para obter categorias de produtos:**
```graphql
query Category {
  products(filters: {productVariantId: XXXXX, ignoreDisplayRules:true}, first: 50) {
    nodes {
      productCategories {
        active
        googleCategories
        hierarchy
        id
        main
        name
        url
      }
    }
  }
}
```

**Vantagem:** Por ser uma query de `products`, múltiplos outros campos de dados do produto podem ser retornados na mesma chamada, potencialmente substituindo chamadas à API Pública.
